# Restaurant-ML-Prediction-Project
This project analyzes restaurant customer data to build a prediction model using an improved and well-structured machine learning workflow.
Project Overview

This notebook follows a complete ML pipeline designed to teach beginners how a real-life prediction model is built.

Steps covered:

Importing libraries
Loading and understanding the dataset
Data cleaning & preprocessing
Handling missing values
Encoding categorical variables
Feature scaling
Train/test split
Model building (multiple algorithms)
Model evaluation (accuracy, confusion matrix, classification report)
Model selection based on performance
